### 🎵 Spotify Viral Hit Predictor

A Machine Learning pipeline that predicts song popularity with **54% accuracy**. Built with Python, Scikit-Learn, and Random Forest.

- **Tech Stack:** Python, Pandas, Scikit-Learn, Random Forest
- **Key Insight:** "Acousticness" and "Valence" (happiness) are stronger predictors of popularity than Genre.
